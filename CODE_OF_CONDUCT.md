# Code of Conduct

## Our standard

We want this project to be a calm, useful place to discuss type, Unicode
and font engineering. Be precise, be patient with people who are learning,
and criticise the work rather than the person.

## Expected behaviour

- Use clear, respectful language.
- Assume good faith and ask for clarification before drawing conclusions.
- Back claims about licensing, rendering or character coverage with a
  source, a file, or a reproducible test.
- Respect that contributors have different levels of familiarity with
  font tooling.

## Unacceptable behaviour

- Personal attacks, harassment, or discriminatory language.
- Publishing someone else's private information.
- Deliberately misleading statements about the licensing status of the
  font files in this repository.
- Submitting contributions that conceal the origin of glyph outlines.

## Scope

This applies to issues, pull requests, discussions, commit messages and
any project-related public space.

## Enforcement

Maintainers may edit or remove comments that violate these standards and
may block repeated offenders. Report concerns by opening a confidential
note to the repository maintainer. There is no separate enforcement body
for this single-maintainer project.
